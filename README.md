# ETロボコン2026 CS大会 モデル図

CS大会に向けた日本語の設計モデル、編集可能なAstah SysMLファイル、10図の画像、トレーサビリティ資料を公開します。地区大会資料・過去の作業リポジトリの履歴は含みません。

- [Webで図一覧を見る](https://takki0525.github.io/etrobo-cs2026-model/cs-2026/design-model/)
- [日本語の説明と図をGitHubで見る](cs-2026/design-model/README.md)
- [Astah SysMLモデルを取得する](cs-2026/design-model/設計モデル_日本語_審査説明版_v4.axmz)
- [要求・実装への対応](cs-2026/design-model/traceability.md)
- [日本語の表示名と実装名の対応](cs-2026/design-model/実装名対応表.md)

設計検討版です。DS-Rは暫定要求、TCは未実施の検証候補。正式要求との接続、実機による検証、物理無線構成の確認は今後の課題です。

AstahモデルとPNGは同じ版です。ファイルの整合性は `python tools/verify_public.py` で確認できます。GitHub Pagesはmainブランチのルートを配信します。
